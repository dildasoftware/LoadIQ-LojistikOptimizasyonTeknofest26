# LoadIQ — TEKNOFEST 2026 Hepsiburada Lojistik Yarışması

**Takım NASİP** tarafından geliştirilen bu proje, TEKNOFEST 2026 Hepsiburada Lojistik Optimizasyon Yarışması kapsamında iki aşamalı olarak ilerlemektedir. Birinci aşama (yarı final) tamamlanmış olup ilgili çözüm `stage1_temel_cozum/` klasöründe arşivlenmiştir. İkinci aşama (Gelişmiş Çözüm) aktif olarak geliştirilmekte olup tüm güncel kaynak kod, veri ve dokümantasyon `stage2_gelismis_cozum/` klasöründe yer almaktadır.

## Klasör Yapısı

| Klasör | Açıklama |
|--------|----------|
| `stage1_temel_cozum/` | Yarı finale çıkaran temel çözüm (tamamlandı, arşiv). |
| `stage2_gelismis_cozum/` | Aktif geliştirilen gelişmiş çözüm — talep tahmini, araç planlama, kısıt denetimi. |
